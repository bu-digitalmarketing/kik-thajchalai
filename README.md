# kik-thajchalai — somvfxcat / ミング

เว็บไซต์ส่วนตัวของ **somvfxcat** พร้อมมาสคอตแมวส้มขาว **ミング (MING)** — ชื่อเดิม "ส้ม"

A personal site for **somvfxcat**, built around **Ming** — an orange-and-white cat who was first called *Som* (ส้ม, Thai for "orange"). The `som` in `somvfxcat` comes from his name.

## What's here

- `index.html` — the entire site. One file, no build step, no dependencies to install.
- `.nojekyll` — tells GitHub Pages to serve the file as-is.

## Features

- **Hand-drawn SVG mascot** of Ming, animated with CSS only: breathing, independent ear twitches,
  swaying tail, swinging collar bell, whisker drift, and a happy squint that opens for a peek every 9s.
- **Three languages** — 日本語 (default) / English / ไทย, switched from the header, remembered per browser.
- **Ming's story** — eight chapters, from stray cat to eleven years at home.
- Light and dark themes, responsive down to phone width, `prefers-reduced-motion` respected.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.

The site will appear at `https://bu-digitalmarketing.github.io/kik-thajchalai/`.

## Fonts

Loaded from Google Fonts: M PLUS Rounded 1c, Zen Maru Gothic, IBM Plex Sans Thai, IBM Plex Mono.
